# 🌦️ Weather App Website

A simple and user-friendly Weather App built using **HTML, CSS, and JavaScript**. The application displays weather-related information with a clean interface and weather images.

## ✨ Features

- 🌤️ Simple and attractive user interface
- 🔍 Search for a city's weather
- 🌡️ Display weather information
- 🌧️ Weather-related images,icons and showing speed of the wind and Humidity. 
- 📱 Responsive styling (depending on screen size)

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **JavaScript** – Application functionality

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or run it using the Live Server extension.
4. Search for a city to explore the weather information, if the weather API is configured.
